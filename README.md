# FootFisio — Sistema de gestión de clínica

Aplicación web desarrollada con React, TypeScript y Vite para gestionar pacientes, citas, historial clínico, pagos, usuarios y reportes.

## Requisitos

- Node.js compatible con la versión de Vite instalada.
- npm.

## Instalación y ejecución

```bash
npm install
npm run dev
```

Vite mostrará en la terminal la dirección local para abrir la aplicación.

## Compilar para producción

```bash
npm run build
npm run preview
```

## Arquitectura de software

La sección **Arquitectura de Software** de la aplicación explica MVC, DAO, SOLID y TDD aplicados como guía de diseño para FootFisio. La documentación ampliada está en `ARQUITECTURA.md`.

**Nota técnica:** los datos de la aplicación son actualmente de demostración y se mantienen en el estado de React. La documentación distingue esta situación de una implementación completa con base de datos y pruebas automatizadas.
